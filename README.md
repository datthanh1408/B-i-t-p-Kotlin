# Bài tập Kotlin - Quản lý điểm sinh viên

Dự án lưu trữ các bài tập lập trình Kotlin cơ bản.

## Nội dung
- **`BaiTapDiem.kt`**: Chương trình nhập thông tin sinh viên, điểm các môn học (Math, Programming, Database), tự động tính tổng điểm, điểm trung bình, tìm điểm cao nhất và đánh giá kết quả (ĐẠT / KHÔNG ĐẠT).

## Hướng dẫn chạy
Biên dịch và chạy chương trình với Kotlin compiler:
```bash
kotlinc BaiTapDiem.kt -include-runtime -d BaiTapDiem.jar
java -jar BaiTapDiem.jar
```
